Basics

What is machine learning?

In normal programming you write the rules. In machine learning the computer finds the rules by studying examples.

AI

Any machine doing something that seems smart (a chess bot).

Machine learning

A part of AI where systems learn from data (Spotify picking songs).

Deep learning

A part of ML using many-layered neural networks (face unlock).
Real lifeYour teacher can’t write rules for every handwriting style. A phone app instead learns from millions of handwriting samples.
Exam tipDefine key terms precisely: model (what is learned), training data (examples used to learn), feature (an input measurement), label (the correct answer).
Basics

Three ways machines learn

Supervised

Learn from examples with answers. Example: predicting your exam grade from hours studied.

Unsupervised

Find hidden groups with no answers given. Example: Netflix grouping viewers with similar taste.

Reinforcement

Learn by trial, error and rewards. Example: a game bot learning to beat a level.

Underfitting vs overfitting

Real lifeUnderfit = only learning “study more = pass”. Overfit = memorising last year’s exact questions. Good fit = understanding the topic.

Fixes for overfitting: more data, a simpler model, stop training earlier, regularisation (penalise complexity), cross-validation (test on several different splits).

Accuracy = 85%

(TP+TN) ÷ all = 85 ÷ 100. Overall correct. Misleading if one class is rare.

Precision = 80%

TP ÷ (TP+FP) = 40 ÷ 50. “When it says spam, is it?”

Recall = 89%

TP ÷ (TP+FN) = 40 ÷ 45. “Of all real spam, how much did it catch?”
Real lifeA cancer screening test should have high recall (don’t miss anyone). A spam filter wants high precision (don’t bin your exam results email).
Advanced

Neural networks

Inspired by the brain. Each neuron multiplies inputs by weights, adds them up, then applies an activation function to decide how strongly to “fire”. Hover over nothing, just read the layers below.

Learning = tuning weights

Gradient descent: like walking downhill in fog to find the lowest error, one small step at a time. The learning rate is your step size: too big and you overshoot; too small and you take forever.

The training loop

Forward pass (make a guess) → compute the loss (how wrong?) → backpropagation (work out which weights caused the error) → update weights → repeat for many epochs.
Real lifeLearning to throw a basketball: each miss tells you to adjust a little (angle, force). Backpropagation is that feedback applied to millions of tiny “knobs”.
Advanced

Deep learning families

CNN

Scans images with small filters: edges → shapes → faces. Used in: Face ID, medical scans, self-driving cars.

RNN / LSTM

Has memory of earlier items in a sequence. Used in: older voice assistants, stock and weather forecasts.

Transformer

Uses attention to see how all words relate at once. Used in: ChatGPT-style chatbots, Google Translate.

GAN

Two networks compete: a forger and a detective. Used in: AI art and deepfakes.

Other advanced terms: transfer learning (reuse a trained model for a new task), natural language processing (understanding text), computer vision (understanding images), hyperparameters (settings you choose before training, like k or learning rate).

Advanced

Reinforcement learning

The agent tries actions, collects rewards, and learns a policy that maximises total reward. It must balance exploration (try new things) and exploitation (use what works).

Real lifeTraining a puppy with treats. Or AlphaGo playing millions of games against itself.
Advanced

Ethics, bias and society

Bias in data

If a hiring tool learns from past hires that were mostly men, it may unfairly favour men. Garbage in, garbage out.

Privacy

Models need lots of personal data. Who owns it? Was consent given? How long is it kept?

Transparency

If a black-box model rejects a loan, can the person get an explanation? This is “explainable AI”.

Accountability & jobs

Who is responsible when a self-driving car crashes? Which jobs will automation change?
