# ML Lab 3D: IB Computer Science Option A4

A visual study site for all 17 IB DP Computer Science Option A4 (machine learning) topics, A4.1.1 to A4.4.2.
Each topic has an interactive 3D lab (Three.js), full notes, common exam mistakes, key terms, a quiz and written practice.

- Open `index.html` (single self-contained file; loads Three.js from cdnjs and fonts from Google Fonts).
- With GitHub Pages enabled: `https://nehasiddiqu.github.io/Machine-Learning-Visual-Guide-/ib-cs-a4-3d-lab/`
- `source/` holds the editable source files and `build.py` that assembles `index.html`.
